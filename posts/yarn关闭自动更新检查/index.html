yarn关闭自动更新检查

2026/10/14 10:29:472 分钟阅读
yarn

背景

在内网执行yarn install安装项目依赖时，经常会出现明明依赖安装完毕了，但yarn的输出一直未结束，卡在提示：

info There appears to be trouble with your network connection. Retrying...

经过排查，发现是yarn在检查更新，导致连接超时。

分析

通过yarn install --verbose查看实时日志：

得知，当前yarn版本为 V1.22.22，阻塞的请求为:

Performing "GET" request to "https://yarnpkg.com/latest-version".

即yarn在后台自检更新。

关闭yarn自检更新功能

通过yarn config set设置yarn配置，关闭自检更新功能：

yarn config set disable-self-update-check true

补充

也可考虑使用离线模式：

# 强制离线模式
yarn install --offline
