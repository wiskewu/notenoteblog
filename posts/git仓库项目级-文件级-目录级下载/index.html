Git仓库项目级、文件级、目录级下载

2026/8/31 14:50:346 分钟阅读
Git

背景

基于不同使用场景，有时候可能需要下载Git完整仓库，有时候可能只需要下载某个文件，有时候可能只需要下载某个目录。

项目级

对于项目级，直接使用 git clone 即可。

git clone https://github.com/user/repo.git

指定分支：

git clone -b main https://github.com/user/repo.git

若只需浅克隆，不下载历史，只拿最新代码，则可以使用：

git clone --depth=1 https://github.com/user/repo.git

文件级

github

在github仓库对应文件页面，可以直接点击下载按钮download raw file进行下载。

代理

也可以通过类似gh-proxy这类代理工具，对特定文件进行下载。 gh-proxy工具支持的文件类型有：

# 分支源码
https://github.com/WJQSERVER-STUDIO/ghproxy/archive/refs/heads/main.zip

# raw文件
https://github.com/WJQSERVER-STUDIO/ghproxy/blob/main/config/config.toml
https://raw.githubusercontent.com/WJQSERVER-STUDIO/ghproxy/refs/heads/main/config/config.toml

# Release源码
https://github.com/WJQSERVER-STUDIO/ghproxy/archive/refs/tags/4.3.4.zip

# Release文件
https://github.com/WJQSERVER-STUDIO/ghproxy/releases/download/4.3.4/ghproxy-linux-amd64.tar.gz

# gist
https://gist.githubusercontent.com/oopsunix/2dbf20f64984773da6740d1d1cf7c2d4/raw/github-blacklist

# api
https://api.github.com/repos/umami-software/umami

# GitHub 头像 (avatars)
https://avatars.githubusercontent.com/u/10000?v=4

# GitHub Desktop 客户端发布文件 (desktop)
https://desktop.githubusercontent.com/releases/3.6.2-beta1-f62b1c7a/GitHubDesktop-x64.zip

# git
git clone https://gh-proxy.com/https://github.com/WJQSERVER-STUDIO/ghproxy.git

目录级

如果只想下载项目中的某个目录，比如skills目录，则可以使用gitfetchpro，例如：

npx gitfetchpro https://github.com/gitlabhq/gitlabhq/tree/master/.claude/skills/glab -o ./skill-glab

详见git-fetch-pro

输入的项目目录格式（带tree的文件夹链接）：

https://github.com/用户名/仓库名/tree/分支名/子文件夹路径
