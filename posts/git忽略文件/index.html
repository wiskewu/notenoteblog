远程仓库配置忽略文件

这是开发过程中最常用的方式，在项目根目录下创建一个 .gitignore 文件，内容示例如下：

# 可以使用'#'添加注释
# 忽略所有的 .a 文件
*.a

# 但跟踪所有的 lib.a，即便你在前面忽略了 .a 文件
!lib.a

# 只忽略当前目录下的 TODO 文件，而不忽略 subdir/TODO
/TODO

# 忽略任何目录下名为 build 的文件夹
build/

# 忽略 doc/notes.txt，但不忽略 doc/server/arch.txt
doc/*.txt

# 忽略 doc/ 目录及其所有子目录下的 .pdf 文件
doc/**/*.pdf

影响范围：所有人，本地及远程仓库。 不多赘述。

全局配置忽略文件

在计算机上的任何 Git 存储库中提交时，可以指示 Git 始终忽略特定文件或目录。

例如，可以使用此功能忽略codegraph生成的.codegraph文件目录，或Trae这类IDE生成的WORKLOG文件夹。

有两种配置方式。

影响范围：全局所有本地git项目，自己；

方式一

具体操作方式是，在用户主目录下的.config文件夹创建一个git/ignore的文件（不带后缀）。即~/.config/git/ignore：

cd ~/.config

# 若不存在git目录，则创建
mkdir git

# 创建ignore文件
cd git && touch ignore

ignore文件内容示例如下：

# 忽略vibecoding生成的日志文件夹
WORKLOG/

# 忽略codegraph生成的文件
.codegraph/

方式二

也可以通过git config命令设置全局忽略文件：

git config --global core.excludesfile ~/.gitignore_global

# 创建ignore文件
cd ~/ && touch .gitignore_global

本地单仓库配置忽略文件

还有一种场景，就是在本地仓库中，需要忽略一些文件，但不想影响其他仓库（即配置不会提交到git追踪记录中）。

这时可以在仓库根目录的.git目录中，创建并编辑.git/info/exclude:

cd .git/info

# 创建exclude文件
touch exclude

exclude文件内容示例如下：

# 忽略vibecoding生成的日志文件夹
WORKLOG/

# 忽略codegraph生成的文件
.codegraph/

影响范围：本地git项目，自己；
